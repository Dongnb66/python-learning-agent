学习闭环 Agent

我把「画像 → 规划 → 检索问答 → 测验 → 复盘 → 自主辅导」串成一条可审计的学习闭环。防幻觉不是叮嘱模型，而是代码层的三道硬约束——这一页让你亲眼看到它们工作。

load_memory→ profile→ planner→ resource→ quiz→ review→ 条件边 → tutor（ReAct ≤4轮）→ save_memory
公网版说明：这是无状态演示——学情只存在你浏览器的 localStorage 里，随请求传入、服务端不落库；检索/阈值/拒答/白名单/规划/题库/辅导规则与本地完整版同源同参数（BM25 bigram 分词、阈值 2.0、top-k 4、ReAct 4 轮上限）。完整的 LangGraph 8 节点编排、SQLite 跨会话记忆与真实 LLM 调用在本地完整版；本页无模型 Key，全部走规则兜底，绝不编造。

1学习画像

告诉我你是谁、想学什么。姓名/专业由与后端同源的正则从你的自我介绍里提取（高置信覆盖），六维画像由表单规则生成。

2学习规划 + 资源推荐（防幻觉三道闸）

规则版规划与本地零 Key 样例同源；资源推荐走真实链路：按步骤标题 BM25 检索（阈值 2.0）→ 空检索代码级拒答 → URL 白名单逐条过滤。

3知识库检索问答（防幻觉可见化）

我把 12 条课程知识库全量打分给你看：只有 BM25 分 > 2.0 的才进候选；一条都没有时我在代码层直接拒答，根本不调用模型。

学习 LangGraph 怎么用 Docker 部署 Python 应用 RAG 防幻觉 语料外话题（看拒答） 零命中话题（看拒答）

4自测测验

种子题库与本地零 Key 样例逐字同源，覆盖本轮计划的三个核心知识点。

5学情复盘（上次 vs 本次）

复盘规则结合画像与测验结果；如果你上次来过（localStorage 里有学情快照），我会给出纵向对比——没有历史就明说首次，不编造「上次」。

6自主辅导节点（ReAct 演示）

这是本地完整版里唯一的自主决策节点：决策 → 调工具 → 观察 → 再决策，最多 4 轮，每轮记入 trace 可审计。公网无 Key 走与后端同构的规则策略（工具真实执行 BM25 检索）；配置了可用 Key 才走模型驱动。
