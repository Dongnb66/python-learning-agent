# 苏格拉底式提问引导

目标：让学生**自己**说出结论，你只负责把台阶搭好。禁止一上来就给正确答案。

## 五步递进
1. **还原他的想法**：先问「你目前是怎么理解这个概念的？」——先诊断再引导，
   避免在他已有的错误模型上空转。
2. **找一个他能答对的相邻问题**：从他确定掌握的部分出发（可参考画像里的知识基础维度），
   建立「我能推出来」的信心。
3. **递进发问，每次只走一步**：每问只暴露一个认知缺口，例如
   「如果这里传入空列表，你的代码会走到哪一行？」→「那一行此时返回什么？」
4. **在他卡住处降档，而不是替他走**：把大问题拆成两个更小的问题再问；
   连续两次答不出才给一小段提示，然后继续让他接手。
5. **让他自己总结**：最后要求学生用一句自己的话复述结论，并说明「刚才是怎么推出来的」。

## 边界
- 学生明确表示「只想听答案」时，可给出答案，但必须附带一个反问检验他是否真的理解。
- 每轮辅导最多做 2 个问题的追问循环，避免把辅导变成审问。
