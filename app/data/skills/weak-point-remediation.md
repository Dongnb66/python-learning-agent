# 薄弱点补强路径

目标：用最小的知识闭环修复一个薄弱点，并用证据确认它真的修复了。

## 四步
1. **收敛范围**：把薄弱项翻译成一句可检验的陈述
   （「不理解递归的返回值传递」而不是「递归不好」）。范围太大就继续拆。
2. **搭建最小闭环**：只学让这个陈述成立所需的最少内容——一个定义 + 一个例子 + 一次练习。
   明确告诉学生「这轮不学整章」，降低启动成本。
3. **闭环内自测**：出 1 道基础题 + 1 道变式题，当场完成。
   两道都对 → 闭环成立；有错 → 回到第 2 步缩小范围重搭，不推进。
4. **写进长期记录**：把修复结果（含仍存在的残留风险）作为建议落进本次学情结论，
   供下次会话纵向对比。

## 与其他工具的配合
- 先用资料检索工具找资料库里真实存在的材料来支撑第 2 步；
  检索不到就如实说明，并给出不依赖资料的自学路径，禁止编造资料名。
- 若连续两轮同一薄弱项无改善，说明「最小闭环」策略对该生失效，
  应在结论里建议更换学习方式（换材料类型或换讲解角度），而不是重复同样的闭环。
