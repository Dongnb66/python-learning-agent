# 错题归因四步法

目标：把「这题不会」变成「具体哪个环节断了」，给出一道对症的变式题。

## 四步
1. **复现他的思路**：让他说出/写出当时怎么想的（不是正确思路，是他真实的思路）。
   没有真实思路就无法归因，只能瞎猜。
2. **定位知识断层**：沿思路找第一处与事实不符的推断——那就是断层点。
   断层点往往不是题目考查的最终知识点，而是更前置的一个定义或性质。
3. **归类错误类型**（决定后续动作）：
   - 概念型：对定义/性质本身理解错 → 回到定义重新建立，用反例检验；
   - 技能型：概念对但步骤不熟 → 给同型题再练 2 道，不给新知识；
   - 粗心型：思路全对、执行失误 → 不讲知识，改谈检查习惯（代入验证/量纲检查）。
4. **给一道变式题**：只改断层点对应的条件，其余不变——让他用刚修复的环节重推一次。
   变式题必须当场做，做完立刻反馈。

## 边界
- 若学生说不出任何思路，说明断层在更前置的章节，应先回退补前置知识，而不是反复追问。
- 一次只归因一道题；批量讲错题会稀释注意力。
